# 配色方案参考

## 概览

本文件定义4种低饱和偏深色系的学习友好型配色方案，适用于笔记排版与思维导图。所有颜色经过精心调配，确保长时间阅读不疲劳，同时保持足够的视觉层次感。

## 方案详情

### 1. 深海蓝 (deep_ocean)

沉稳理性的蓝灰色调，适合技术类、逻辑性强的内容。

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | #F7F9FA | 极浅蓝灰，减少纯白刺眼 |
| 主标题色 | #2C3E50 | 深蓝灰，权威感 |
| 副标题色 | #34495E | 中蓝灰 |
| 强调色 | #5D7B93 | 柔和蓝，用于划线/标记线 |
| 辅助色 | #7F8C8D | 中性灰，用于次要信息 |
| 正文色 | #1A252F | 近黑蓝灰，高可读性 |
| 高亮背景 | #E8EDF1 | 浅蓝灰，用于术语高亮底色 |
| 引用背景 | #EDF1F4 | 极浅蓝，引用块底色 |

适用场景: 技术文档、编程笔记、数学/物理学习笔记、商业分析

### 2. 暮光紫 (twilight_purple)

优雅沉静的紫色调，适合人文、艺术、创意类内容。

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | #F8F6FA | 极浅紫，柔和温暖 |
| 主标题色 | #4A3B5C | 深紫，优雅感 |
| 副标题色 | #5D4E6D | 中紫 |
| 强调色 | #7B6B8A | 柔和薰衣草紫，用于划线 |
| 辅助色 | #8E7C9E | 浅紫灰 |
| 正文色 | #2D1F3D | 深紫黑，高对比度 |
| 高亮背景 | #EDE8F2 | 浅紫，术语高亮底色 |
| 引用背景 | #F0ECF4 | 极浅紫，引用块底色 |

适用场景: 文学笔记、历史学习、艺术设计、心理学笔记、读书笔记

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | #F5F8F6 | 极浅绿灰，清新 |

| 副标题色 | #3D5C4E | 中绿 |

| 辅助色 | #6E8F7E | 浅绿灰 |
| 正文色 | #1A2F26 | 深绿黑，高可读性 |
| 高亮背景 | #E2EDE8 | 浅绿，术语高亮底色 |

适用场景: 生物学习、环境科学、医学笔记、健康记录、自然观察

### 4. 暖灰棕 (warm_grey)

温暖舒适的棕灰色调，适合综合类、日常学习内容。

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | #F8F6F4 | 暖白，舒适不冷 |
| 主标题色 | #4A4039 | 深棕灰，温暖感 |
| 副标题色 | #5C524A | 中棕 |
| 强调色 | #7B6E63 | 柔和棕，用于划线 |

| 正文色 | #2D2520 | 深棕黑，高可读性 |
| 高亮背景 | #EDE8E3 | 浅棕，术语高亮底色 |
| 引用背景 | #F0ECE8 | 极浅棕，引用块底色 |

适用场景: 综合学习笔记、语言学习、考试复习、日常知识整理

## 选择建议

- 理性/技术内容 -> 深海蓝
- 人文/创意内容 -> 暮光紫
- 自然/科学内容 -> 森林绿
- 通用/日常内容 -> 暖灰棕
- 长时间阅读: 所有方案均经过低饱和处理，适合长时间学习
- 打印友好: 所有方案在打印时保持良好可读性
