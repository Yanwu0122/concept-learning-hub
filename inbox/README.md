# 📥 Inbox · 素材投递口

这里是知识库的**入口**：把想学、想整理进知识库的原始素材丢进本目录（网页链接存成 `.txt/.md`、文章、课件摘录、随手记、PDF 均可），然后对 WorkBuddy 说一句：

> 「把 inbox 里的内容整理进知识库」

AI 会加载 `knowledge-organizer` Skill，自动完成：**读内容 → 识别领域 → 分门别类 → 生成/整理笔记 → 登记 catalog → 重建门户 → 推送**。

## 使用约定

- 一个文件尽量对应一个主题，方便归类
- 文件里最好带上来源链接或出处（AI 会把它们写进笔记的参考来源）
- 已处理完的素材会被移走/清空，本目录长期保持为空 + 本说明文件
- 也可以不用本目录：直接把链接或文本粘贴给 AI 说「把这篇收进知识库」即可
